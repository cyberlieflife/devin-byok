Devin BYOK

macOS:
1. Open the .dmg and drag Devin BYOK to Applications
2. Open Devin BYOK from Applications
3. Configure models/providers in GUI
4. Click Start service, then fully restart Devin

The app stays visible in the Dock and uses a deer icon.

Windows:
1. Run devin-byok-gui.exe
2. Configure models/providers in GUI
3. Click Start service, then fully restart Devin

Stop: click Stop service in GUI (auto restore)
